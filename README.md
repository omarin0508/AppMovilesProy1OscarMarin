# Proyecto Programado 1 - Portafolio Profesional Interactivo

Curso: Programacion para Dispositivos Moviles (TPA-4001)

Base tecnica inicial para una aplicacion movil de portafolio profesional interactivo, desarrollada con React Native, Expo y TypeScript.

## Tecnologias iniciales

- React Native
- Expo
- TypeScript
- React Navigation

## Instalacion

```bash
npm install
```

## Iniciar Expo

```bash
npm start
```
